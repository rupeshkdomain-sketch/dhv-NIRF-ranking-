# NIRF cleaning decisions

## Source and scope

- Raw annual CSVs are preserved unchanged in `data/raw/`. The current source set is the NIRF Overall ranking for 2017–2025.
- The source has `Institute ID`, `Name`, `City`, `State`, `Score`, and `Rank`; each source file represents the `Overall` category.
- `year` is read from the four digit year in the source filename. `original_category` retains the source category label; `category` is its comparable standardized form.

## Cleaning

- UTF-8 BOM is accepted. Header whitespace is stripped.
- Names, city and state values have the scraped `More Details |` suffixes, repeated whitespace, and surrounding punctuation removed. No source file is overwritten.
- Scores are parsed as numeric after removing commas. Invalid scores become missing and are listed in `missing_fields`.
- Ranks are parsed as integers. For a range such as `101-150`, `rank` stores the lower bound (101) and `rank_band` stores the original range (`101-150`). This preserves usable ordering while retaining the published band. A single rank has a missing `rank_band`.
- Entirely empty rows are discarded. Partially populated records are retained and their missing columns are listed in `missing_fields`.
- Institution names are standardized through `data/reference/institution_mapping.csv`. Its initial suggestions are generated by conservative RapidFuzz matching and must be reviewed, especially the 29 labels grouped beyond exact spelling. The generated `NIRF-xxxxx` IDs are stable keys for this source set, not official NIRF identifiers.
- State mappings normalize legacy names when present (including Orissa → Odisha, Uttaranchal → Uttarakhand, Pondicherry → Puducherry). Other names retain their source spelling.
- Category mapping currently maps each year's Overall source label to `Overall`.

## Master assembly and duplicates

- The master schema is `year, category, original_category, institution_id, institution, city, state, score, rank, rank_band, missing_fields`.
- Duplicate `(year, category, institution_id)` records are sorted by number of populated fields (most first), then rank (best/lowest first); the first record is retained.
- `data/processed/nirf_master.parquet` is the consolidated table consumed by downstream analysis.

## Missing values and validation

- `missing_fields` is an audit column. Null `rank_band` is expected for single rank values and does not indicate a missing rank.
- The validator reports null counts per column and fails on schema mismatch, duplicate keys, years outside 2000–2100, and ranks outside 1–10000.
- In the current 2017–2025 build, 901 records were retained; no duplicate keys, missing core values, or invalid ranks were found.
- Re-run `02_clean.py`, `03_standardize.py`, `04_build_master.py`, then `validate.py` after changing mappings or source files.
